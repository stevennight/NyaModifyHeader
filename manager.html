响应调试覆盖 可选，仅影响页面 Fetch / XHR

修改页面 JavaScript 读取到的响应状态码。

启用后整段替换响应内容，支持空字符串。

这是页面级本地调试覆盖，不会改变 Chrome Network 面板中的真实 HTTP 响应，也不作用于图片、脚本等非 Fetch / XHR 资源。

网址匹配方式

使用 * 匹配任意字符，例如 *://*.example.com/*。

0 个模式 · 所有网站

每行一个模式，最多 20 个；留空代表所有已授权网站。

可在网址前加方法覆盖，例如 [OPTIONS] https://api.example.com/* 或 [GET,POST] https://api.example.com/items/*；[ALL] 表示该行允许全部方法。

高级选项

命中任一排除模式时，规则不会运行。

也支持方法前缀，例如 [OPTIONS] https://api.example.com/private/*；未加前缀时排除全部方法。

请求方法 可选，空白表示全部

例如只选择 OPTIONS，可让响应 Header 规则只作用于 CORS 预检请求。
